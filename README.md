# Zihan Hei Academic Website V3

## Preview locally

1. Extract the folder to an English-only path, for example `C:\Quarto\Zihan_Hei_Academic_Website_V3`.
2. Open `Zihan_Hei_Academic_Website.Rproj` in RStudio.
3. In the Terminal, run:

```bash
quarto preview
```

Do not open every `.qmd` file separately. Quarto reads `_quarto.yml` and builds the entire website.

## Render the website

```bash
quarto render
```

The completed website will be placed in `_site`.

## Render the PDF CV

```bash
quarto render cv-pdf.qmd
```

## Publish to Quarto Pub

```bash
quarto publish quarto-pub
```

## Publish to GitHub Pages

Create a GitHub repository, push this folder to it, and enable GitHub Pages through GitHub Actions. A workflow is included in `.github/workflows/publish.yml`.

## Edit interactive graphics

The radar chart and mentor network are self-contained SVG visualizations generated by `assets/visualizations.js`. No external JavaScript package or internet connection is required. Edit the labels, scores, mentors, and descriptions in that file.
