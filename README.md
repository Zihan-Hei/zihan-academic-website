# Zihan Hei Academic Website V3

## Preview locally

1. Extract the folder to an English-only path, for example `C:\Quarto\Zihan_Hei_Academic_Website_V3`.
2. Open `Zihan_Hei_Academic_Website.Rproj` in RStudio.
3. In the Terminal, run:

```bash
quarto preview
```

Do not open every `.qmd` file separately. Quarto reads `_quarto.yml` and builds the entire website.

## Render the website

```bash
quarto render
```

The completed website will be placed in `_site`.

## Render the PDF CV

```bash
quarto render cv-pdf.qmd
```

## Publish to Quarto Pub

```bash
quarto publish quarto-pub
```

## Publish to GitHub Pages

Create a GitHub repository, push this folder to it, and enable GitHub Pages through GitHub Actions. A workflow is included in `.github/workflows/publish.yml`.

## Edit interactive graphics

The radar chart and mentor network are self-contained SVG visualizations generated by `assets/visualizations.js`. No external JavaScript package or internet connection is required. Edit the labels, scores, mentors, and descriptions in that file.

## Add personal photographs

Place photos in `assets/photos/`, then replace a placeholder in `index.qmd` with:

```markdown
![](assets/photos/your-photo.jpg)
```

The Tools and platforms section now uses one compact ecosystem panel. Related tools remain grouped by workflow type, but the individual logos are smaller and all clusters appear inside a single visual container.

## Version 7 visualization fix

The logo files are explicitly included in the rendered site through `project.resources` in `_quarto.yml`. This fixes the broken-image problem that can occur when image paths are created dynamically in JavaScript, because Quarto otherwise may not copy those files into `_site`.

The Tools and Platforms section is now one interactive connected network. Drag to pan, scroll to zoom, use Reset to restore the view, and Export PNG to save the figure.


## Version 8 update

The Tools and Platforms section now uses the selected static network infographic stored at `assets/tools-platforms-network.png`. This avoids broken logo paths and guarantees that the design renders consistently in local preview, Quarto Pub, and GitHub Pages.


## V10 interactive tools network
